Fyers login now runs server-side — there is nothing to do here.

Where it moved. Open the app and click the red 🔴 Fyers indicator in the header. That runs the same fyers-auto-login Edge Function the daily cron runs, and it writes today's token itself.
Why. This page kept its own copy of the login flow with a hardcoded App ID. It missed the move to the SEBI-compliant -200 app, stopped being able to mint a token, and reported success anyway — so a live order was rejected with NO_BROKER_TOKEN while the screen said the login had worked. One owning implementation removes that whole class of failure.
If the indicator still shows red after clicking it, the auto-login itself failed — the app will show the actual error. Check the fyers-auto-login Edge Function logs and the api_last_error column on investor_broker_accounts.
