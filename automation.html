Trade tags …

Applied to each transaction written from a Katalysthive fill, at the moment it is written. Same tag field as the rest of the app — type to search existing tags, Enter to add, × to remove. Stored on the strategy row (auto_strategies.metadata.transaction_tags). Leave empty and trades import as blank.
Changes apply to trades booked from now on. Transactions already in the book are never re-tagged — edit those in the Trading module if you want them changed.
